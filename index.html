分子与细胞

细胞的分子组成 · 结构与功能 · 物质与能量代谢 · 增殖分化

1走近细胞高频 ★★★★★

知识框架：生命系统结构层次 → 细胞学说 → 原核细胞与真核细胞 → 病毒

生命系统的结构层次

  • 由小到大：细胞 → 组织 → 器官 → 系统（植物无） → 个体 → 种群 → 群落 → 生态系统 → 生物圈
  • 细胞是最基本的生命系统；病毒、分子、原子不属于生命系统。
  • 种群=同种生物全部个体；群落=一定区域所有种群；生态系统=群落+非生物环境。

细胞学说（施莱登、施旺）

  • ① 细胞是一个有机体，一切动植物都由细胞发育而来，并由细胞和细胞产物构成；
  • ② 细胞是一个相对独立的单位；
  • ③ 新细胞由老细胞分裂产生。
  • 意义：揭示了细胞统一性和生物体结构统一性，为进化论提供依据。

易错
  • 蓝细菌含叶绿素和藻蓝素，能进行光合作用，但没有叶绿体；硝化细菌能进行化能合成作用。
  • 有细胞壁≠植物细胞；有核膜≠原核。判断关键看有无以核膜为界限的细胞核。

病毒

  • 无细胞结构，由核酸（DNA 或 RNA）+ 蛋白质外壳组成。
  • 只能寄生在活细胞内，用宿主细胞原料和能量增殖（不能独立代谢、不能直接用培养基培养）。
  • HIV、流感病毒为 RNA 病毒；T2 噬菌体为 DNA 病毒。

实验：使用高倍显微镜 实验

  • 步骤：低倍镜下找→移（把目标移到视野中央）→转（转动转换器换高倍）→调（调细准焦螺旋，不能动粗准焦）
  • 放大倍数=目镜×物镜；放大的是长度或宽度，不是面积。
  • 高倍镜下视野变暗、细胞数少、细胞大；物像移动方向与装片移动方向相反。
  • 污点判断：移动装片/转动目镜/转动转换器逐一排除。

2组成细胞的分子高频 ★★★★☆

知识框架：元素 → 无机物（水·无机盐）→ 有机物（糖类·脂质·蛋白质·核酸）

元素与无机物

  • 大量元素：C、H、O、N、P、S、K、Ca、Mg；微量元素：Fe、Mn、Zn、Cu、B、Mo（"铁锰锌铜硼钼"）。
  • 基本元素 C；鲜重含量最多O，干重最多C；Mg 参与叶绿素合成，Fe 参与血红蛋白。
  • 水：自由水（良好溶剂、运输、参与代谢）越多代谢越旺盛；结合水（结构成分）越多抗逆性越强。
  • 无机盐：构成化合物（如 P→核酸/ATP，I→甲状腺激素）；维持细胞渗透压、酸碱平衡（缓冲对 H₂CO₃/NaHCO₃）。

脂质

  • 脂肪：储能（1g≈39kJ，同质量糖类约17kJ）、保温、缓冲；等量糖类氧化分解耗 O₂ 多、放能多。
  • 磷脂：构成生物膜（含 C H O N P）。
  • 固醇：胆固醇（构成动物细胞膜、参与脂质运输）、性激素（促进生殖器官发育）、维生素D（促进 Ca、P 吸收）。

蛋白质——生命活动的主要承担者

  • 基本单位：氨基酸（至少含一个氨基和一个羧基，且连在同一碳原子上，约 21 种）。
  • 结合方式：脱水缩合形成肽键（-CO-NH-）。
  • 结构层次：氨基酸 → 肽链 → 盘曲折叠 → 蛋白质（空间结构）
  • 多样性原因：氨基酸种类、数目、排列顺序不同 + 肽链的空间结构不同。
  • 功能：结构蛋白、催化（酶）、运输（血红蛋白）、调节（激素）、免疫（抗体）、传递信息（受体）。
脱水缩合计算：肽键数 = 脱去水分子数 = 氨基酸数 n − 肽链数 m至少含氨基 m 个、羧基 m 个（在肽链两端）；蛋白质相对分子质量 = n×氨基酸平均相对分子质量 − 18×(n−m)

3细胞的基本结构高频 ★★★★☆

知识框架：细胞膜 → 细胞器分工协作 → 细胞核 → 分泌蛋白合成运输

细胞膜——系统的边界

  • 组成：磷脂双分子层（基本支架）+ 蛋白质（镶嵌/贯穿）+ 少量糖类（糖蛋白=受体，具识别作用）。
  • 流动镶嵌模型：磷脂分子和多数蛋白质可运动，膜具流动性（结构基础）；功能上具选择透过性。
  • 三大功能：将细胞与外界分隔开；控制物质进出；进行细胞间信息交流（信号分子—受体；胞间连丝）。
  • 制备纯净细胞膜材料：哺乳动物成熟红细胞（无核、无众多细胞器，吸水涨破）

细胞器——分工与合作

细胞器分布功能要点
线粒体动植物有氧呼吸主要场所（双层膜、内膜折叠成嵴）
叶绿体绿色植物叶肉光合作用场所（双层膜、基粒含色素）
内质网动植物蛋白质加工运输、脂质合成（粗面/滑面）
高尔基体动植物加工、分类、包装；植物中与细胞壁形成有关
核糖体原核/真核都有蛋白质合成场所（无膜）
溶酶体动物分解衰老损伤细胞器、吞噬异物（含多种水解酶）
液泡植物细胞液渗透压、充盈使细胞坚挺
中心体动物、低等植物与有丝分裂纺锤体形成有关（无膜）
分类记忆
  • 双层膜：线粒体、叶绿体；单层膜：内质网、高尔基体、液泡、溶酶体；无膜：核糖体、中心体。
  • 动植物都有：线粒体、内质网、高尔基体、核糖体；植物特有：叶绿体、液泡；动物和低等植物特有：中心体。

细胞核——遗传信息库、代谢调控中心

  • 核膜（双层）、核孔（大分子进出，如 mRNA、蛋白质；选择性）、染色质（DNA+蛋白质，是遗传信息载体）、核仁（与核糖体形成有关）。
  • 染色质与染色体是同一种物质在细胞不同时期的不同存在形式。
  • 证明细胞核功能的实验：蝾螈受精卵横缢实验、伞藻嫁接与核移植实验。

分泌蛋白的合成与运输（示踪法）

核糖体合成肽链 → 内质网加工 → 高尔基体再加工 → 细胞膜胞吐 → 细胞外用放射性同位素 3H 标记亮氨酸，放射性先后出现在：核糖体 → 内质网 → 高尔基体 → 细胞膜

全过程需要线粒体供能；运输依赖囊泡（膜流动性的体现）。

细胞骨架与生物膜系统 高频

  • 细胞骨架：蛋白质纤维（微管、微丝）构成，维持形态、支撑细胞器、与运动分裂有关。
  • 生物膜系统=细胞膜+细胞器膜+核膜；原核细胞没有（仅细胞膜）。
  • 各种膜成分相似（磷脂+蛋白质），结构功能紧密联系，实现物质运输、能量转换、信息传递。

4物质跨膜运输高频 ★★★☆☆

知识框架：渗透作用 → 被动运输（自由扩散·协助扩散）→ 主动运输 → 胞吞胞吐

四种运输方式对比

方式方向载体蛋白能量实例
自由扩散高浓度→低浓度无不消耗O₂、CO₂、水、甘油、乙醇、苯、脂肪酸
协助扩散高→低有（通道蛋白/载体蛋白）不消耗葡萄糖进入红细胞、K⁺经通道外流
主动运输低→高有消耗 ATP葡萄糖/氨基酸进小肠上皮、离子逆浓度、Na⁺-K⁺泵
胞吞/胞吐—无消耗 ATP（依赖膜流动性）白细胞吞噬细菌、分泌蛋白/神经递质释放
易错辨析
  • 协助扩散和主动运输都需要载体蛋白（具专一性，数量有限——存在饱和效应）；判断是否消耗能量是关键。
  • 葡萄糖进红细胞=协助扩散；进小肠上皮细胞、肾小管重吸收=主动运输。
  • 自由扩散与协助扩散合称被动运输，顺浓度梯度，不消耗能量。

渗透作用与质壁分离

  • 渗透作用条件：半透膜 + 膜两侧有浓度差（水从低浓度溶液流向高浓度溶液）。
  • 植物成熟细胞的原生质层（细胞膜+液泡膜+两膜之间细胞质）=半透膜。
  • 质壁分离：外界溶液浓度>细胞液浓度时，细胞失水，液泡缩小、原生质层与细胞壁分离。
  • 质壁分离自动复原：KNO₃、尿素等可被吸收的溶质，先分离后自动复原（先失水后吸水）。

实验：观察质壁分离与复原 实验

  • 材料：紫色洋葱鳞片叶外表皮（中央大液泡，紫色便于观察）。
  • 试剂：0.3 g/mL 蔗糖溶液（分离）→ 清水（复原），自身对照。
  • 低倍镜即可完成全程观察，不能选用死细胞、根尖分生区细胞（无大液泡）。
  • 判断细胞死活、测定细胞液浓度范围也常用此实验原理。

5酶与 ATP高频 ★★★★☆

知识框架：酶的本质·特性·作用机理 → 影响酶活性的因素 → ATP 结构 → ATP 与 ADP 相互转化

酶——生物催化剂

  • 化学本质：绝大多数是蛋白质，少数是 RNA（具催化作用）。
  • 作用机理：显著降低化学反应的活化能（不提供能量、不改变化学平衡）。
  • 特性：高效性（比无机催化剂效率高 10⁷–10¹³ 倍）、专一性（一种酶只催化一种或一类反应）、作用条件温和（需适宜温度与 pH）。
  • 酶的活性受温度、pH 影响；低温抑制活性（可恢复），高温/过酸/过碱使酶失活（不可逆，空间结构被破坏）。

ATP——直接能源物质

  • 结构简式：A-P~P~P（A=腺苷，P=磷酸基团，~=高能磷酸键）。
  • 水解时末端高能磷酸键断裂，释放能量，变成 ADP+Pi。
  • 合成与水解是可逆反应吗？——不是：物质可逆，但条件、场所、能量来源均不同（不是同一反应）。
  • ATP 是细胞的直接能源物质；糖类是主要能源，脂肪是主要储能物质，太阳能是最终能量来源。
  • 细胞内 ATP 含量很少但转化迅速，维持动态平衡。

实验：酶的专一性、高效性与条件探究 实验

  • 专一性：淀粉酶分别处理淀粉+蔗糖，用斐林试剂检测（只淀粉组出现砖红色）。
  • 高效性：H₂O₂ + 过氧化氢酶 vs 无机催化剂 Fe³⁺，比较气泡产生速率。
  • 温度影响：淀粉酶+淀粉在不同温度保温后，用碘液检测（不能用斐林试剂，因需水浴加热干扰温度变量）。
  • pH 影响：可用 H₂O₂ 酶+不同 pH 缓冲液（H₂O₂ 本身受温度影响，不宜研究温度）。
  • 对照实验原则：单一变量 + 对照 + 平行重复。

6细胞呼吸高频 ★★★★★

知识框架：有氧呼吸（三阶段）→ 无氧呼吸（两类型）→ 影响因素与应用 → 探究实验

有氧呼吸（总反应式）

第一阶段细胞质基质葡萄糖分解为丙酮酸丙酮酸、[H](NADH)、少量 ATP少量
第二阶段线粒体基质丙酮酸+水彻底分解CO₂、[H]、少量 ATP少量
第三阶段线粒体内膜[H] 与 O₂ 结合生成水H₂O、大量 ATP大量

无氧呼吸

C₆H₁₂O₆ ──酶──→ 2C₂H₅OH + 2CO₂ + 少量能量酒精发酵：酵母菌、大多数植物
C₆H₁₂O₆ ──酶──→ 2C₃H₆O₃ + 少量能量乳酸发酵：动物、人、乳酸菌、马铃薯块茎、甜菜块根
  • 第一阶段与有氧呼吸完全相同（都在细胞质基质）；第二阶段的产物不同。
  • 无氧呼吸有机物氧化不彻底，能量释放少，大部分能量仍留在产物中。

影响因素与应用

  • 温度：影响酶活性。储存果蔬、粮食：零上低温、低氧、干燥。
  • O₂ 浓度：零氧时只进行无氧呼吸；储存以低氧（约5%）为最佳，既抑制无氧呼吸又减弱有氧呼吸。
  • CO₂ 浓度：CO₂ 浓度升高抑制呼吸作用（保鲜常用）。
  • 松土、增施农家肥、稻田晒田→促进根的有氧呼吸；伤口包扎透气→抑制破伤风杆菌（厌氧菌）繁殖。
  • 剧烈运动后肌肉酸痛=乳酸积累；慢跑（有氧）供能更持久。

实验：探究酵母菌细胞呼吸的方式 实验

  • 装置：甲组通气（有氧），乙组密闭（无氧），设置相互对照。
  • CO₂ 检测：澄清石灰水变浑浊 / 溴麝香草酚蓝（BTB）溶液由蓝变绿再变黄（CO₂ 越多变化越快）。
  • 酒精检测：酸性条件下橙色的重铬酸钾变为灰绿色（需在无氧条件下取培养液）。

影响光合作用强度的因素

  • 光照强度：低于光补偿点（光合=呼吸）净积累为负；光饱和点后光合不再增强。阴生植物光补偿点低。
  • CO₂ 浓度：CO₂ 饱和点前呈正相关；施用有机肥、通风可增产。
  • 温度：影响酶活性，白天适当升温、夜间降温（降低呼吸消耗）利于增产。
  • 矿质元素：N、Mg（叶绿素）、P（ATP、膜）、K 等。
  • 净光合速率 = 总光合速率 − 呼吸速率；叶片 O₂ 释放/CO₂ 吸收表示净光合。

实验：绿叶中色素的提取和分离 实验

  • 提取：无水乙醇（溶解色素）+ 二氧化硅（研磨充分）+ 碳酸钙（防止色素被破坏）。
  • 分离：纸层析法，层析液（石油醚等）；滤纸条剪去两角（减小边缘效应）。
  • 结果（自上而下）：胡萝卜素（橙黄）→ 叶黄素（黄）→ 叶绿素 a（蓝绿，含量最多）→ 叶绿素 b（黄绿）。
  • 色素吸收可见光，叶绿素主要吸收红光和蓝紫光，类胡萝卜素主要吸收蓝紫光。

化能合成作用

  • 硝化细菌利用无机物氧化（NH₃→HNO₂→HNO₃）释放的化学能，将 CO₂ 和 H₂O 合成有机物。
  • 自养生物：光合型（绿色植物、蓝细菌）+ 化能合成型（硝化细菌）；异养生物：动物、真菌、多数细菌。

  • 分化：细胞在形态结构功能上发生稳定性差异；实质是基因的选择性表达（遗传物质不变）。分化程度越高，全能性越低。
  • 全能性：已分化细胞具有发育成完整有机体的潜能（细胞含全套遗传物质）。植物细胞全能性易表现（组织培养）；动物克隆（核移植）。
  • 衰老特征：水分减少（体积变小）、酶活性降低、色素积累、细胞核增大染色加深、物质运输功能降低。
  • 凋亡：基因控制的程序性死亡（对生物体有利，如蝌蚪尾消失、手指形成）。
  • 癌变：特征——无限增殖、形态结构改变、表面糖蛋白减少（易扩散转移）；原因——原癌基因（调控细胞周期）与抑癌基因（抑制增殖）突变。

1遗传因子的发现高频 ★★★★★

知识框架：豌豆杂交实验 → 分离定律 → 自由组合定律 → 亲子代推断与概率计算

孟德尔实验成功的原因与基本概念

  • 选材：豌豆自花传粉、闭花受粉（自然状态下纯种），有易于区分的相对性状。
  • 方法：假说—演绎法（观察现象→提出假说→演绎推理→实验验证：测交）。
  • 核心概念：等位基因（同源染色体同一位置控制相对性状的基因，如 A/a）；基因型、表现型、纯合子、杂合子；显性、隐性；杂交（×）、自交（⊗）、测交（Aa×aa）。
分离定律（一对相对性状）
  • 实质：减Ⅰ后期等位基因随同源染色体分开而分离，分别进入不同配子。
  • 自交后代：基因型 1:2:1；表现型 3:1（显:隐）。
  • 测交后代：1:1（Aa:aa），可检测 F₁ 基因型及产生配子的种类比例。
自由组合定律（两对及以上）
  • 实质：减Ⅰ后期非同源染色体上的非等位基因自由组合。
  • YyRr 自交：配子 4 种（YR:Yr:yR:yr=1:1:1:1），后代表现型 9:3:3:1。
  • YyRr 测交：表现型 1:1:1:1。
  • n 对独立遗传杂合子自交：配子 2ⁿ 种，表现型 2ⁿ 种（完全显性），基因型 3ⁿ 种。

显隐性判断与亲子代推断

  • 方法一：性状分离——亲代相同性状杂交，后代出现新性状→新性状为隐性（如 Aa×Aa→aa）。
  • 方法二：纯合×杂合或不同性状亲本杂交后代只出现一种性状→该性状为显性。
  • 正推：按分离/自由组合配子棋盘法或分枝法。
  • 逆推：根据后代分离比反推亲本基因型（3:1→Aa×Aa；1:1→Aa×aa；9:3:3:1→AaBb×AaBb）。

多对性状组合概率速算

患病概率组合（独立事件）患甲病=m，患乙病=n → 只患甲=m(1−n)；两病兼患=mn；只患一种=m+n−2mn；至少患一种=m+n−mn；不患病=(1−m)(1−n)
  • 多对基因分解为单个分离定律分别计算，再相乘（乘法原理）。
  • Aa×Aa 后代杂合子概率 1/2、纯合子 1/2；AaBb×AaBb 后代纯合子 (1/2)×(1/2)=1/4。

  • 萨顿：类比推理提出"基因在染色体上"（假说，需实验验证）。
  • 摩尔根：假说—演绎法，用果蝇白眼突变体实验证明基因在染色体上（白眼基因在 X 染色体上）。
  • 果蝇优点：易饲养、繁殖快、后代多、相对性状明显、染色体少（4 对）。

人类遗传病与预防

  • 类型：单基因遗传病（如白化病、色盲）、多基因遗传病（冠心病、青少年型糖尿病，群体发病率高）、染色体异常遗传病（21 三体综合征）。
  • 监测预防：遗传咨询 + 产前诊断（羊水检查、B 超、基因检测）。
  • 21 三体：多一条 21 号染色体（减数分裂异常，染色体数目变异）。

5基因突变及其他变异、育种高频 ★★★★★

知识框架：基因突变 → 基因重组 → 染色体变异 → 育种方法对比

基因突变

  • 概念：DNA 分子中发生碱基的替换、增添或缺失，引起基因碱基序列改变。
  • 实例：镰刀型细胞贫血症（血红蛋白 β 链第 6 位谷氨酸→缬氨酸，碱基 A→T）。
  • 特点：普遍性、随机性、不定向性、低频性、多害少利性。
  • 时期：主要在分裂间期（DNA 复制时）；体细胞突变一般不遗传，生殖细胞突变可遗传。
  • 意义：产生新基因的途径，生物变异的根本来源，进化的原材料。

基因重组

  • 来源：① 减Ⅰ后期非同源染色体自由组合；② 减Ⅰ前期交叉互换；③ 基因工程（人为）。
  • 结果：产生新的基因型（不产生新基因）。
  • 意义：生物变异的重要来源之一，形成生物多样性。

现代生物进化理论要点

  • 种群是生物进化的基本单位；基因库=种群全部个体所含全部基因。

  • 遗传平衡（哈代-温伯格）：种群极大、随机交配、无突变迁移选择时，p²+2pq+q²=1（p=A、q=a 频率）。
  • 伴 X 基因频率：按 X 染色体数计算（女性 2 条、男性 1 条）。
  • 自然选择、突变、迁移、非随机交配都会改变基因频率。

  • 共同进化：不同物种之间、生物与无机环境之间在相互影响中不断进化和发展。
  • 生物多样性 = 基因多样性 + 物种多样性 + 生态系统多样性。
  • 生物多样性是共同进化的结果。

1人体的内环境与稳态高频 ★★★★☆

知识框架：体液与内环境 → 内环境成分与理化性质 → 稳态调节机制

体液与内环境组成

  • 体液 = 细胞内液（约 2/3）+ 细胞外液（约 1/3，即内环境）。
  • 内环境 = 血浆 + 组织液 + 淋巴（淋巴液）；是细胞生活的液体环境。
  • 组成关系：血浆 ⇌ 组织液 ⇄ 淋巴（组织液→淋巴→左右锁骨下静脉→血浆）。
  • 内环境中不存在：血红蛋白（红细胞内）、呼吸酶（细胞内）、DNA 聚合酶、ATP 合成酶等胞内酶；存在：葡萄糖、氨基酸、激素、抗体、神经递质、O₂、CO₂、血浆蛋白等。

内环境的理化性质与稳态

  • 渗透压：主要由血浆中蛋白质和无机盐决定，细胞外液渗透压 90% 以上来自 Na⁺、Cl⁻。
  • 酸碱度：pH 7.35–7.45，靠缓冲对 HCO₃⁻/H₂CO₃、HPO₄²⁻/H₂PO₄⁻ 调节。
  • 温度：37℃ 左右（体温调节中枢在下丘脑）。
  • 稳态实质：内环境各种化学成分和理化性质保持相对稳定。
  • 调节机制：神经—体液—免疫调节网络是机体维持稳态的主要调节机制；调节能力有限度。

2神经调节高频 ★★★★★

知识框架：反射弧 → 兴奋在神经纤维上传导 → 突触传递 → 神经系统的分级调节

反射与反射弧

  • 神经调节的基本方式是反射，结构基础是反射弧：感受器→传入神经→神经中枢→传出神经→效应器。
  • 反射弧任一环节受损反射都不能完成；只有感受器受损→既无感觉也无运动；传出神经受损→有感觉无运动。
  • 效应器 = 运动神经末梢 + 它所支配的肌肉或腺体；兴奋传导方向与神经冲动方向相反（在反射弧内单向）。

兴奋在神经纤维上的传导

  • 静息电位：外正内负（约 −70mV），成因：K⁺ 外流（协助扩散）。
  • 动作电位：外负内正，成因：Na⁺ 内流（协助扩散，顺浓度梯度）。
  • 传导方式：局部电流；离体神经纤维上双向传导，反射弧内单向。
  • 膜电位曲线速记：上坡=Na⁺ 内流，下坡=K⁺ 外流恢复静息。

兴奋在神经元之间的传递（突触）

  • 突触 = 突触前膜 + 突触间隙 + 突触后膜（后膜上有特异性受体）。
  • 过程：突触前膜释放神经递质（胞吐，需耗能）→ 与后膜受体结合 → 引发后膜电位变化 → 递质被降解或回收。
  • 传递特点：单向传递（只能由突触前膜→后膜）；比神经纤维传导慢（有突触延搁）。
  • 神经递质分兴奋性（乙酰胆碱）与抑制性（γ-氨基丁酸、甘氨酸）两类。

神经系统的分级调节与大脑皮层 高频

  • 躯体运动中枢在大脑皮层（对侧支配）；低级中枢（脊髓、脑干）受高级中枢（大脑皮层）调控（如排尿）。
  • 脑干：呼吸、心跳中枢；下丘脑：体温、水盐、血糖调节中枢；小脑：维持身体平衡；脊髓：低级反射中枢。
  • 人脑高级功能：语言、学习记忆、思维；S 区（运动性语言中枢，受损不会说）、H 区（听觉性，听不懂）、V 区（视觉性，看不懂）、W 区（书写性，不会写）。
  • 条件反射建立在非条件反射基础上，需大脑皮层参与（如望梅止渴、铃声喂食）。

4免疫调节高频 ★★★★☆

免疫系统的组成与三道防线

  • 组成：免疫器官（胸腺、骨髓、脾、淋巴结等）+ 免疫细胞（吞噬细胞、T/B 淋巴细胞）+ 免疫活性物质（抗体、淋巴因子、溶菌酶）。

  • T 细胞在胸腺成熟，B 细胞在骨髓成熟。

  • 体液免疫（对付细胞外抗原）：抗原→B 细胞（多数需辅助性 T 细胞协助）→增殖分化→浆细胞（分泌抗体）+记忆 B 细胞；抗体+抗原结合形成沉淀/细胞集团，被吞噬细胞清除。

  • 吞噬细胞在两类免疫中都起摄取处理呈递抗原的作用；记忆细胞二次应答：更快更强（更短时间产生大量抗体）。

  • 直接决定因素：出生率、死亡率、迁入率、迁出率。

  • 种群密度≠总数量（要除以空间大小），取样要随机。

调查方法

方法适用要点/公式
样方法植物、活动能力弱的动物（蚜虫、跳蝻）、虫卵随机取样，常用五点取样法、等距取样法；密度 = 全部样方个体数 ÷ 样方面积和
标志重捕法活动能力强、活动范围大的动物（鼠、鸟、鱼）N = M×n÷m（M 标记数，n 重捕总数，m 重捕中带标记数）
误差分析
  • 标志物脱落、标志后易被捕食→估算值偏大；初次捕获标志使动物更易被再捕→估算偏小。
  • 样方边缘个体计数：计上不计下、计左不计右（只计相邻两边及其夹角）。

种群数量增长的两种模型

模型条件曲线特征公式/数量变化
J 型食物空间充足、无天敌、气候适宜（理想条件）指数增长，增长率不变Nt = N₀λᵗ（λ>1）
S 型自然条件（资源有限）先增后稳，K/2 时增长速率最大环境容纳量 K 值，在 K 值附近波动
K 值应用（高频）
  • 渔业捕捞：捕捞后使种群数量保持在K/2 左右（增长速率最大，恢复最快）——但可持续获得最大日捕捞量应在 K/2 之后、接近 K 时捕捞。
  • 害虫防治：尽早防（越早越易控制）；降低环境容纳量（清除孳生地）是治本措施。
  • λ 的辨析：λ>1 种群增长、λ=1 稳定、λ<1 下降；λ 是倍数不是增长率（增长率=λ−1）。

2群落及其演替高频 ★★★☆☆

知识框架：群落结构 → 种间关系 → 群落演替

群落的结构

  • 垂直结构：分层现象（光照、温度等）——植物分层，动物随之分层；意义：充分利用空间资源。
  • 水平结构：镶嵌分布（地形、湿度、光照差异）。
  • 群落中物种数目的多少称为物种丰富度。

种间关系（区分要点）

关系要点曲线特征
捕食一种生物以另一种为食数量先增先减，波动跟随（不同步）
竞争争夺资源空间；可共存可淘汰一种上升一种下降（你死我活）或均减少
寄生寄主受害（一般不致死）寄生者数量一般多于寄主
互利共生彼此有利、相互依存数量同步同向变化（同增同减）

群落演替

  • 初生演替：从未有过植被的裸地（裸岩、沙丘、冰川泥）开始，速度慢、时间长：裸岩→地衣→苔藓→草本→灌木→森林。
  • 次生演替：原有植被破坏但土壤条件保留（弃耕农田、火烧地、砍伐地），速度快。
  • 演替是优势种更替，最终达到与当地气候土壤相适应的顶极群落（并非总是森林，取决于环境）。
  • 人类活动可改变演替的方向和速度（往往使其偏离自然演替方向）。

3生态系统及其稳定性高频 ★★★★★

知识框架：结构（组成成分+营养结构）→ 能量流动 → 物质循环 → 信息传递 → 稳定性

生态系统的结构

组成成分地位/作用举例
非生物的物质和能量基础光、热、水、空气、无机盐
生产者最主要成分，基石，将无机物→有机物（自养）绿色植物、蓝细菌、硝化细菌
消费者加速物质循环、帮助传粉传播种子（异养）动物、寄生细菌、菟丝子
分解者把有机物分解为无机物，不可缺少腐生细菌真菌、蚯蚓、蜣螂、秃鹫
  • 营养结构 = 食物链 + 食物网；食物链起点是生产者，终点是最高营养级消费者，分解者不进入食物链。
  • 营养级 = 食物链中的环节位置；一种生物可占多个营养级（食物网中）。

能量流动

  • 起点：生产者固定太阳能；渠道：食物链食物网。
  • 特点：单向流动、逐级递减；传递效率 10%–20%（相邻营养级同化量之比）。
  • 摄入量 = 同化量 + 粪便量（粪便属上一营养级）；同化量 = 呼吸散失 + 用于生长发育繁殖 = 呼吸 + 流向下一营养级 + 流向分解者 + 未利用。
  • 金字塔：能量金字塔不会倒置（数量金字塔可倒置：树—虫—鸟）。
  • 研究意义：科学规划食物链，使人获得更多能量（如草→牛→人）；实现能量的多级利用（桑基鱼塘）。

物质循环（碳循环）

  • 碳进入生物群落：光合作用、化能合成作用（CO₂→有机物）；返回无机环境：呼吸作用、分解者的分解、化石燃料燃烧。
  • 碳在无机环境与生物群落间以CO₂形式循环；在生物群落内部以含碳有机物形式沿食物链流动。
  • 温室效应：化石燃料燃烧排放 CO₂ 过多→碳循环失衡。

信息传递

  • 类型：物理信息（光声温湿度磁）、化学信息（信息素、化学物质）、行为信息（蜜蜂跳舞、孔雀开屏）。
  • 作用：生命活动正常进行、种群繁衍、调节种间关系维持生态系统稳定。
  • 应用：信息素诱捕害虫（生物防治）、模拟动物信息吸引传粉。

生态系统的稳定性

  • 基础：负反馈调节（越多→抑制增多，维持稳态的核心机制）。
  • 抵抗力稳定性：抵抗干扰保持原状的能力（与营养结构复杂程度正相关）；
  • 恢复力稳定性：受破坏后恢复的能力（营养结构复杂则恢复慢）。
  • 两者负相关；营养结构越复杂，自我调节能力越强（但有一定限度）。

4人与环境高频 ★★★☆☆

知识框架：人口与环境问题 → 生物多样性及其保护 → 生态工程基本原理

全球生态环境问题

  • 温室效应（CO₂）、臭氧层破坏（氟利昂）、酸雨（SO₂ 等）、水体富营养化（N、P 过多→水华/赤潮）、土地荒漠化、生物多样性锐减。
  • 可持续发展：既满足当代人需求，又不损害后代人满足其需求的能力。

生物多样性及其价值与保护

  • 层次：基因（遗传）多样性、物种多样性、生态系统多样性。
  • 价值：直接价值（食用药用观赏）、间接价值（生态功能，如调节气候——大于直接价值）、潜在价值。
  • 保护：就地保护（建立自然保护区——最有效）、易地保护（迁地）、建立基因库、立法、生物技术（人工繁殖）。
  • 保护≠禁止开发利用，是合理利用。

生态工程基本原理

  • 自生：通过生物组分自我组织、自我优化、自我调节维持系统功能（选择适合物种、协调比例）。
  • 循环：物质循环再生（桑基鱼塘、无废弃物农业）。
  • 协调：生物与环境、生物与生物协调平衡（不超过环境承载力）。
  • 整体：社会—经济—自然复合系统统一协调（整体性原理）。
  • 生态工程遵循"少消耗、多效益、可持续"，但不能违背自然规律。生态农业原理：物质循环再生+能量多级利用。

1发酵工程高频 ★★★★☆

知识框架：微生物培养（培养基·无菌技术）→ 传统发酵食品 → 发酵工程流程与应用

微生物的实验室培养

  • 培养基：按物理性质分液体/固体（加琼脂）；按成分分天然、合成；按用途分选择、鉴别。
  • 灭菌与消毒区别：灭菌杀灭一切微生物（高压蒸汽、干热、灼烧、照射）；消毒仅杀死部分（煮沸、巴氏、酒精、氯气）。
  • 无菌操作：接种环/涂布器灼烧灭菌，培养基、培养皿高压蒸汽灭菌，超净工作台紫外线+酒精擦拭。
  • 接种方法：平板划线法（分离纯化）、稀释涂布平板法（计数，每个活菌长一个菌落）。
  • 计数偏小原因：两个或多个细菌连在一起只形成一个菌落。

传统发酵食品

产品菌种代谢类型关键条件
果酒酵母菌兼性厌氧前期通气繁殖，后期无氧发酵；18–25℃
果醋醋酸菌好氧一直通气；30–35℃；糖源不足时乙醇→醋酸
腐乳毛霉等好氧蛋白酶、脂肪酶分解大分子
泡菜乳酸菌厌氧密封无氧发酵；亚硝酸盐含量先升后降
易错
  • 果酒制作中不需严格灭菌（抑制杂菌：冲洗不消毒、发酵液酸性缺氧）；果醋发酵表面菌膜是醋酸菌。
  • 泡菜坛要"泡菜水淹没菜料、密封"，防止乳酸菌厌氧环境被破坏。

发酵工程的基本环节与应用

选育菌种 → 扩大培养 → 配制培养基灭菌 → 接种发酵（控制温度 pH 溶氧）→ 分离提纯产物发酵罐中需监测溶氧量、pH、温度；产物有菌体本身（单细胞蛋白）与代谢产物（抗生素、氨基酸、柠檬酸）
  • 应用：食品（味精、酱油、酸奶）、医药（青霉素、胰岛素、疫苗）、化工原料（酒精、乳酸）、环境保护（微生物降解）。

2细胞工程高频 ★★★★☆

知识框架：植物细胞工程 → 动物细胞工程 → 干细胞与克隆

植物细胞工程

  • 植物组织培养（原理：细胞全能性）：外植体→脱分化→愈伤组织→再分化→完整植株；条件：无菌 + 适宜激素（生长素/细胞分裂素比例）。
  • 植物体细胞杂交：去除细胞壁（纤维素酶、果胶酶）→原生质体融合（物理：电激/离心；化学：PEG）→再生细胞壁→组织培养；克服远缘杂交不亲和障碍（如马铃薯-番茄）。
  • 应用：快速繁殖、培育无病毒苗（茎尖培养）、突变体利用、细胞产物工厂化生产。

动物细胞工程

  • 动物细胞培养（原理：细胞增殖）：材料取幼龄动物组织，胰蛋白酶分散成单个细胞；培养基含血清；气体环境 95% 空气+5% CO₂。
  • 动物细胞融合（原理：细胞膜流动性）：常用灭活病毒/仙台病毒或 PEG；杂交细胞含双亲遗传物质。
  • 核移植（克隆）：去核卵母细胞 + 供体细胞核→重组细胞→胚胎→克隆动物（克隆羊"多莉"）。

单克隆抗体 高频

  • 原理：B 淋巴细胞（产生特定抗体但不能无限增殖）+ 骨髓瘤细胞（能无限增殖）→杂交瘤细胞（兼有两亲本优点）。
  • 筛选：第一次用选择培养基（HAT）淘汰未融合及自身融合细胞；第二次克隆化培养+抗体检测，选出能产生所需抗体的杂交瘤细胞。
  • 应用：诊断（"生物导弹"靶向治疗）、治疗、研究。

干细胞与应用

  • 类型：胚胎干细胞（全能性最高，可发育成各种组织细胞）、成体干细胞（造血干细胞、神经干细胞，多能）。
  • 应用：白血病骨髓移植（造血干细胞）、组织修复、iPS（诱导多能干细胞）避免伦理争议。

3基因工程高频 ★★★★★（压轴）

知识框架：三大工具 → 基本操作程序 → PCR → 应用与安全

基因工程三大工具

工具作用要点
限制性内切酶（分子手术刀）切割 DNA识别特定核苷酸序列，在特定位点切断磷酸二酯键，产生黏性末端或平末端
DNA 连接酶（分子缝合针）连接 DNA 片段缝合磷酸二酯键（不能连接单链、无识别特异性）
载体（分子运输车）携带目的基因进入受体细胞常用质粒（还有噬菌体、动植物病毒）；含复制原点、标记基因（便于筛选）、一个至多个限制酶切割位点（多克隆位点）
易错
  • 限制酶切的是DNA（脱氧核苷酸间的磷酸二酯键），不是蛋白质；DNA 聚合酶连接单个核苷酸，DNA 连接酶连接两个片段——二者不同。
  • 目的基因与载体用同一种限制酶切割→相同黏性末端→才能正确连接（也要防止自身环化，常双酶切）。
  • 标记基因作用：检测筛选含目的基因的受体细胞（如氨苄青霉素抗性基因、荧光蛋白基因）。

基本操作程序（四步）

① 目的基因的筛选与获取 → ② 基因表达载体的构建（核心） → ③ 将目的基因导入受体细胞 → ④ 目的基因的检测与鉴定
  • 表达载体组成：目的基因 + 启动子（RNA 聚合酶识别结合位点）+ 终止子 + 标记基因 + 复制原点。
  • 导入：植物常用农杆菌转化法（Ti 质粒 T-DNA 可转移）、基因枪、花粉管通道；动物常用显微注射（受精卵）；微生物常用 Ca²⁺ 处理（感受态细胞）。
  • 检测：① 分子水平——DNA 分子杂交（是否导入）、分子杂交（是否转录）、抗原-抗体杂交（是否翻译）；② 个体水平——抗虫接种实验。

PCR——多聚酶链式反应

  • 原理：DNA 半保留复制（体外）；需要引物（DNA 合成起始需引物，Taq 酶从 3′端延伸）。
  • 循环：变性（90℃以上解旋）→ 复性（55℃左右引物结合）→ 延伸（72℃ Taq 酶合成）。
  • 特点：Taq 酶（耐高温 DNA 聚合酶）；指数扩增 2ⁿ；需两种引物。

应用

  • 转基因作物（抗虫棉：Bt 毒蛋白基因）、转基因动物（乳腺生物反应器生产药物蛋白）、基因治疗、基因诊断（DNA 探针）、蛋白质工程（改造蛋白质结构→改造基因）。
  • 蛋白质工程流程：预期功能→设计蛋白质结构→推测氨基酸序列→找到对应脱氧核苷酸序列（基因）→改造基因。

4胚胎工程高频 ★★★☆☆

知识框架：体外受精 → 早期胚胎培养 → 胚胎移植 → 胚胎分割

体外受精与早期胚胎培养

  • 卵母细胞需培养至减Ⅱ中期（成熟）才可受精；精子需获能处理。
  • 受精在体外培养液中进行；受精卵发育：桑葚胚→囊胚（内细胞团→胚胎干细胞来源；滋养层→胎盘胎膜）→原肠胚。

胚胎移植与胚胎分割

  • 胚胎移植：供体（良种）与受体母畜同期发情处理；受体的生理状态与供体相同（不需同一遗传性状）。
  • 胚胎分割：用分割针/刀将桑葚胚或囊胚均等分割→遗传物质相同（无性繁殖）；滋养层细胞可用于性别鉴定。
  • "试管婴儿"= 体外受精+胚胎移植（有性生殖）；"设计试管婴儿"需植入前遗传学诊断。

转基因生物的安全性

遗传平衡p²+2pq+q²=1（p=A，q=a，随机交配稳定）
DNA 复制 n 次需游离碱基 = 一条链的该碱基数 × (2ⁿ−1)
翻译氨基酸数 = 密码子数 = 反密码子数；DNA 碱基数 : mRNA 碱基数 : 氨基酸数 = 6:3:1

分离比速判法

  • 后代 3:1 → 杂合×杂合（Aa×Aa）；1:1 → 测交（Aa×aa）；全显 → AA×__；全隐 → aa×aa。
  • 9:3:3:1 → 双杂自交；1:1:1:1 → 双杂测交；3:1:3:1 → 一杂自交一杂测交。
  • 多基因时逐对分析再相乘，避免一次考虑多对。

系谱图解题流程

  • ① 判断显隐性（无中生有→隐；有中生无→显）；
  • ② 判断是否伴性（口诀见必修二第4章）；
  • ③ 写出已知个体的表现型基因型（含部分未知）；
  • ④ 计算目标概率，注意"性别已知/未知"（如"生一男孩患病"与"生一个患病男孩"概率不同，后者需乘1/2）。

A2实验设计答题模板高考必考

实验设计四要素与对照类型

要素说明举例（探究光照对种子萌发的影响）
自变量人为改变的量，只能有一个光照条件（有光/无光）
因变量随自变量变化的可观测指标萌发率、发芽时间
无关变量需保持相同且适宜温度、水分、氧气、种子数量、种类
对照提供比较基准有光组为实验组，无光组为对照组
对照类型
  • 空白对照：不加处理（如清水组）。
  • 自身对照：前后自身比较（质壁分离复原）。
  • 相互对照：多个实验组互相对比（不同温度组）。
  • 条件对照：施加非研究因素（如浇蒸馏水对照浇清水组）。
答题万能句式
  • 目的：探究/验证"自变量"对"因变量"的影响。
  • 思路：取若干组生长状况相同（且数量相等）的材料，分别置于不同自变量的条件下，其他条件相同且适宜，培养一段时间后，观察并记录因变量指标。
  • 预期：若实验组结果明显高于/低于对照组，则说明……；若无明显差异，则说明……。
  • 结论：先写事实再写因果，语言表述完整，不写"可能"。

A4易错易混 100 条考前必过一遍

  1. 病毒不属于生命系统，也不属于原核生物，只能寄生在活细胞中。
  2. 蓝细菌是原核生物，有叶绿素和藻蓝素但无叶绿体。
  3. 支原体无细胞壁，是最小的原核生物。
  4. 细胞是生命系统最基本的层次，病毒不是。
  5. 蛋白质基本单位是氨基酸（21种），不是核苷酸。
  6. 氨基酸至少含一个氨基和一个羧基，且连在同一碳原子上。
  7. 高温使蛋白质变性是破坏空间结构，肽键不断裂。
  8. 肽键数=氨基酸数−肽链数；环状多肽肽键数=氨基酸数。
  9. 细胞中有 8 种核苷酸，病毒只有 4 种。
  10. DNA 特有碱基 T、五碳糖为脱氧核糖；RNA 特有 U、核糖。
  11. 斐林试剂现配现用、等量混合、水浴加热；双缩脲先加 A 后加 B、不加热。
  12. 脂肪鉴定用苏丹Ⅲ（橘黄）/Ⅳ（红），50% 酒精洗浮色，需显微观察。
  13. 自由水比例高则代谢旺盛，结合水比例高则抗逆性强。
  14. 无机盐不提供能量，主要维持渗透压和酸碱平衡。
  15. 淀粉、纤维素、糖原的基本单位都是葡萄糖。
  16. 脂肪是主要储能物质，糖类是主要能源物质，ATP 是直接能源。
  17. 磷脂含 C、H、O、N、P，构成生物膜的基本支架。
  18. 性激素是固醇（脂质），化学本质不是蛋白质。
  19. 细胞膜结构为流动镶嵌模型，具流动性和选择透过性。
  20. 糖蛋白分布在膜外侧，与识别、保护、信息交流有关。
  21. 哺乳动物成熟红细胞无细胞核和众多细胞器，是制膜材料。
  22. 无膜细胞器：核糖体、中心体；双层膜：线粒体、叶绿体。
  23. 原核细胞唯一细胞器是核糖体。
  24. 分泌蛋白途径：核糖体→内质网→高尔基体→细胞膜（线粒体供能）。
  25. 细胞骨架是蛋白质纤维，与运动、分裂有关。
  26. 核孔具有选择性，DNA 不能通过核孔出细胞核。
  27. 染色质与染色体是同种物质在不同时期的不同形态。
  28. 协助扩散顺浓度梯度、需载体、不耗能。
  29. 主动运输可逆浓度梯度，需载体和能量（ATP）。
  30. 葡萄糖进红细胞是协助扩散；进小肠上皮细胞是主动运输。
  31. 自由扩散实例：O₂、CO₂、水、甘油、乙醇、苯、脂肪酸。
  32. 质壁分离需：活细胞、大液泡、外界溶液浓度高于细胞液。
  33. KNO₃、尿素、甘油溶液中质壁分离可自动复原。
  34. 酶只降低活化能，不提供能量、不改变平衡点。
  35. 酶绝大多数是蛋白质，少数是 RNA。
  36. 高温、过酸、过碱使酶失活（不可逆）；低温抑制活性（可恢复）。
  37. ATP 水解与合成不是可逆反应：条件、场所、能量来源均不同。
  38. 光合作用释放的 O₂ 全部来自水（鲁宾、卡门证实）。
  39. 光反应产物 ATP、NADPH 供暗反应利用，暗反应消耗 ATP。
  40. 停止光照：C₃ 增多、C₅ 减少；降低 CO₂：C₃ 减少、C₅ 增多。
  41. 滤纸条自上而下：胡萝卜素、叶黄素、叶绿素 a、叶绿素 b。
  42. 提取色素：无水乙醇+SiO₂+CaCO₃；分离用层析液（纸层析法）。
  43. 有氧呼吸第三阶段在线粒体内膜，[H]与O₂结合生成水并释放大量能量。
  44. 人体无氧呼吸只产生乳酸，不产生 CO₂。
  45. 有氧呼吸与无氧呼吸第一阶段完全相同，都在细胞质基质。
  46. 有丝分裂后期染色体数加倍、染色单体数为 0。
  47. 减数分裂染色体数目减半发生在减Ⅰ（同源染色体分离）。
  48. 交叉互换发生在减Ⅰ前期同源染色体的非姐妹染色单体之间。
  49. 精子形成过程均等分裂；卵细胞形成过程不均等分裂。
  50. 受精作用使染色体恢复 2n，细胞质遗传物质几乎全来自母方。
  51. 豌豆自花传粉、闭花受粉，自然状态下为纯种。
  52. 测交是与隐性纯合子杂交，可检测 F₁ 的基因型及配子比例。
  53. 分离定律的实质：等位基因随同源染色体分开而分离。
  54. 自由组合定律实质：非同源染色体上的非等位基因自由组合。
  55. 9:3:3:1 是两对独立遗传完全显性双杂自交的结果。
  56. 萨顿用类比推理提出基因在染色体上，摩尔根用假说-演绎法证明。
  57. 噬菌体侵染实验证明 DNA 是遗传物质，但不能证明蛋白质不是。
  58. 32P 标记的 DNA 进入细菌（沉淀物）；35S 标记的蛋白质留外壳（上清液）。
  59. DNA 双链中 A=T、G=C，任意两不互补碱基之和占 50%。
  60. DNA 复制为半保留复制、边解旋边复制，发生在分裂间期。
  61. 复制 n 次共形成 2ⁿ 个 DNA，其中含母链的恒为 2 个。
  62. 转录产物是 mRNA、tRNA、rRNA。
  63. 密码子 64 种、61 种编码氨基酸；终止密码子 UAA、UAG、UGA。
  64. 一种 tRNA 只能转运一种氨基酸，tRNA 反密码子 61 种。
  65. 细胞分化的实质是基因的选择性表达，遗传物质不变。
  66. 基因突变产生新基因（根本来源），基因重组产生新基因型。
  67. 基因突变特点：普遍性、随机性、不定向性、低频性、多害少利性。
  68. 染色体结构变异：缺失、重复、倒位、易位（易位发生于非同源染色体间）。
  69. 单倍体由配子直接发育而来，不一定只有一个染色体组。
  70. 秋水仙素抑制纺锤体形成，使染色体数目加倍。
  71. 单倍体育种明显缩短育种年限，后代均为纯合子。
  72. 21 三体综合征属于染色体数目变异。
  73. 伴 X 隐性遗传：男性患者多于女性，具交叉遗传特点。
  74. 抗维生素 D 佝偻病是伴 X 显性遗传，女性患者多于男性。
  75. 系谱判断：无中生有为隐性，有中生无为显性。
  76. 种群是生物进化的基本单位，进化的实质是基因频率的改变。
  77. 突变和基因重组为进化提供原材料，自然选择决定进化方向。
  78. 隔离是物种形成的必要条件，生殖隔离是新物种形成的标志。
  79. 内环境即细胞外液：血浆、组织液、淋巴。
  80. 血浆蛋白在内环境中，血红蛋白在红细胞内、不属于内环境。
  81. 细胞外液渗透压 90% 以上来自 Na⁺ 和 Cl⁻。
  82. 稳态调节机制是神经—体液—免疫调节网络。
  83. 静息电位成因 K⁺ 外流，动作电位成因 Na⁺ 内流（均顺浓度梯度）。
  84. 兴奋在神经纤维上双向传导，经突触单向传递。
  85. 突触处信号转变：电信号→化学信号→电信号。
  86. 神经递质经胞吐释放，作用后被降解或回收。
  87. 胰岛素是唯一能降低血糖的激素；与胰高血糖素相互拮抗。
  88. 抗利尿激素由下丘脑合成、垂体释放，促进肾小管重吸收水。
  89. 甲状腺激素分泌受下丘脑-垂体分级调节和负反馈调节。

  91. 过敏反应是免疫防御功能过强；艾滋病（HIV 攻击辅助性 T 细胞）是免疫缺陷。

  93. 生长素作用具有两重性：低浓度促进、高浓度抑制；根比芽比茎敏感。

  98. 生态系统的基石是生产者，分解者是必不可少的成分。
  99. 初生演替序列：裸岩→地衣→苔藓→草本→灌木→森林。
  100. 标志重捕法 N=M×n/m，标志物脱落会使估算值偏大。
