# 高中生物三年知识大全

依据新课标人教版教材（必修一、必修二、选择性必修一/二/三）整理的高中生物三年知识速查网页，面向甘肃及全国高中生物教师、学生一轮复习与考前速查。

## 内容结构

| 模块 | 内容 |
|---|---|
| 必修一 · 分子与细胞 | 走近细胞、组成细胞的分子、细胞结构、跨膜运输、酶与ATP、细胞呼吸、光合作用、细胞增殖与分化 |
| 必修二 · 遗传与进化 | 遗传定律、减数分裂、基因的本质与表达、伴性遗传、变异与育种、生物的进化 |
| 选必一 · 稳态与调节 | 内环境、神经调节、体液调节、免疫调节、植物激素 |
| 选必二 · 生物与环境 | 种群、群落、生态系统、人与环境 |
| 选必三 · 生物技术与工程 | 发酵、细胞工程、基因工程、胚胎工程、安全伦理 |
| 附录 · 高考工具箱 | 遗传计算速算、实验设计模板、科学史实验汇总、易错易混100条、答题规范 |

## 功能

- 全站关键词搜索（自动高亮）
- 章节目录滚动定位
- 桌面 / 手机响应式布局，支持打印
- 每章按"知识框架 → 核心概念 → 重点突破 → 公式计算 → 易错提醒 → 实验速记 → 高频考点"组织

## 使用

直接打开 `index.html` 即可使用，无需联网（离线可用）。
